# Proyecto UHO-Dev

Este proyecto es una aplicación web desarrollada con React y Tailwind CSS. A continuación se describen los archivos y su propósito dentro del proyecto.

## Estructura del Proyecto

```
tuhoclient
├── src
│   ├── pages
│   │   └── Home.tsx        # Componente principal de la página de inicio.
│   ├── App.css             # Estilos CSS personalizados y de Tailwind.
│   └── index.tsx           # Punto de entrada de la aplicación.
├── package.json             # Configuración de npm y dependencias.
├── tailwind.config.js       # Configuración de Tailwind CSS.
└── README.md                # Documentación del proyecto.
```

## Instalación

Para instalar las dependencias del proyecto, ejecuta el siguiente comando en la raíz del proyecto:

```
npm install
```

## Ejecución

Para iniciar la aplicación en modo de desarrollo, utiliza el siguiente comando:

```
npm start
```

Esto abrirá la aplicación en tu navegador predeterminado.

## Personalización

Puedes personalizar el tema de la aplicación modificando el archivo `tailwind.config.js`. Aquí puedes ajustar colores, fuentes y otros aspectos del diseño.
